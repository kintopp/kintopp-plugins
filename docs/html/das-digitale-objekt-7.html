Cultural Heritage MCP Servers and Research Scenarios

The MCP servers below were developed by the Research and Infrastructure Support (RISE) group at the University of Basel. We are particularly interested in exploring the research opportunities, methodological risks, and technical challenges posed by retrieving and analysing data with LLMs. If you would like to collaborate with us in this area, please get in touch.

Rijksmuseum MCP Plus

https://github.com/kintopp/rijksmuseum-mcp-plus

Unofficial MCP server for the Rijksmuseum collections with enhanced metadata, semantic, visual, and full-text search, provenance analysis, similarity comparisons and spatial queries. Research Scenarios.

Rijksmuseum Iconclass MCP

https://github.com/kintopp/rijksmuseum-iconclass-mcp

Iconclass MCP server for the Rijksmuseum with support for semantic search and ArtResearch consortium queries. The server provides access to over 1.3 million open-access Iconclass notations — all of the c. 39,000 base concepts and c. 1.3 million key-expanded variants that add modifiers like posture, context, or symbolism. Research Scenarios.

Globalise MCP

https://github.com/kintopp/globalise-mcp

Unofficial MCP Server for the Globalise project’s Dutch East India Company (VOC) corpus. The collection focuses on the Overgekomen Brieven en Papieren which were sent by the VOC in Batavia to the Dutch Republic in the 17th-18th centuries and are now held by the Dutch National Archives. Research Scenarios.

Odeuropa EOKG MCP

https://github.com/kintopp/odeuropa-eokg-mcp

An MCP server for the European Olfactory Knowledge Graph (EOKG): c. 2.4M smell references machine-extracted by the Odeuropa project from European texts (English, French, Italian, Slovenian, German, Dutch) and c. 44,000 artworks, mostly 1600–1920. Research Scenarios.

Books as Data MCP

https://github.com/kintopp/books-as-data

A prototype of an MCP server for the Swiss Books as Data collection comprised of printed works published between 1700 and 1900 from the University Library of Bern (UB Bern), the Zentralbibliothek Zürich (ZB Zurich), the Central and University Library of Lucerne (ZHB Lucerne), and the University Library Basel (UB Basel). Research Scenarios.
