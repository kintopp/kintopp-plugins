## Cultural Heritage MCP Servers and Research Scenarios 

### Rijksmuseum MCP Plus

[https://github.com/kintopp/rijksmuseum-mcp-plus](https://github.com/kintopp/rijksmuseum-mcp-plus)

Unofficial MCP server for the Rijksmuseum collections with enhanced metadata, semantic, visual, and full-text search, provenance analysis, similarity comparisons and spatial queries. *[Research Scenarios](https://github.com/kintopp/rijksmuseum-mcp-plus/blob/main/docs/research-scenarios.md).*

### Rijksmuseum Iconclass MCP

[https://github.com/kintopp/rijksmuseum-iconclass-mcp](https://github.com/kintopp/rijksmuseum-iconclass-mcp)

Iconclass MCP server for the Rijksmuseum with support for semantic search and ArtResearch consortium queries. *[Research Scenarios](https://github.com/kintopp/rijksmuseum-iconclass-mcp/blob/main/docs/example-prompts.md).*

### Globalise MCP

[https://github.com/kintopp/globalise-mcp](https://github.com/kintopp/globalise-mcp)

Unofficial MCP Server for the GLOBALISE project's Dutch East India Company (VOC) corpus. *[Research Scenarios](https://github.com/kintopp/globalise-mcp/blob/main/globalise-mcp-server/docs/research-scenarios.md).*

### Odeuropa EOKG MCP

[https://github.com/kintopp/odeuropa-eokg-mcp](https://github.com/kintopp/odeuropa-eokg-mcp)

An MCP server for the European Olfactory Knowledge Graph (EOKG): c. 2.4M smell references machine-extracted by the [Odeuropa](https://odeuropa.eu) project from European texts (English, French, Italian, Slovenian, German, Dutch) and c. 44,000 artworks, mostly 1600–1920. *[Research Scenarios](https://claude.ai/artifact/SzxMnGF8HC1yFhj1sqqDbW).*

### Books as Data

[https://github.com/kintopp/books-as-data](https://github.com/kintopp/books-as-data)

A prototype of an MCP server for the Swiss [Books as Data](https://books-as-data.ch) collection comprised of printed works published between 1700 and 1900 from the University Library of Bern (UB Bern), the Zentralbibliothek Zürich (ZB Zurich), the Central and University Library of Lucerne (ZHB Lucerne), and the University Library Basel (UB Basel). *[Research Scenarios](https://claude.ai/artifact/MmwpeVQ688weSSucHd7jnL).*
