## Model Context Protocol (MCP) Demos

### Rijksmuseum MCP Plus

Unofficial MCP server for the Rijksmuseum collections with enhanced metadata, semantic, visual, and full-text search, provenance analysis, similarity comparisons and spatial queries.

[https://github.com/kintopp/rijksmuseum-mcp-plus](https://github.com/kintopp/rijksmuseum-mcp-plus)

### Rijksmuseum Iconclass MCP

Iconclass MCP server for the Rijksmuseum with support for semantic search and ArtResearch consortium queries.

[https://github.com/kintopp/rijksmuseum-iconclass-mcp](https://github.com/kintopp/rijksmuseum-iconclass-mcp)

### Globalise MCP

Unofficial MCP Server for the GLOBALISE Dutch East India Company corpus.

[https://github.com/kintopp/globalise-mcp](https://github.com/kintopp/globalise-mcp)

### Odeuropa EOKG MCP

An MCP server for the European Olfactory Knowledge Graph (EOKG): c. 2.4M smell references machine-extracted by the [Odeuropa](https://odeuropa.eu) project from European texts (English, French, Italian, Slovenian, German, Dutch) and c. 44,000 artworks, mostly 1600–1920.

[https://github.com/kintopp/odeuropa-eokg-mcp](https://github.com/kintopp/odeuropa-eokg-mcp)

### SKKG MCP

An MCP server for the collection of the Stiftung für Kunst, Kultur und Geschichte (SKKG) in Winterthur. It holds about 64,000 objects, including Swiss paintings of the 19th and 20th centuries, works on paper, furniture, arms, coins, and everyday objects. Its records include images, provenance chains, literature, exhibitions, and SKKG's own acquisitions with their prices.

[https://github.com/kintopp/skkg-mcp/tree/main](https://github.com/kintopp/skkg-mcp/tree/main)
